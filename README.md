# Solene – AI Based Mental Health Stress & Burnout Detection System

## 🌸 Overview

Solene is an AI-powered emotional wellness and stress management platform designed to help users identify stress and burnout levels while also providing supportive wellness interaction through AI-based conversations, mindfulness activities, journaling, and emotional wellness resources.

The system combines:

* Machine Learning for stress prediction
* Gemini AI for emotional wellness conversations
* Flask for backend development
* HTML, CSS, and JavaScript for frontend interaction

Solene is designed to create a calm, interactive, and supportive mental wellness experience.
